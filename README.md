## v0.8.4

罗德岛行动日历是一款明日方舟信息聚合插件，聚合 PRTS、anything-ics 与 ArknightsGachaData，生成 1440px 宽的活动、寻访与今日作战信息长图，并提供干员生日文字查询、当天生日祝福和独立的自动生日祝贺。

版本更新记录见 [CHANGELOG.md](CHANGELOG.md)。

## ✨ 功能特点

- **今日作战信息**：按 PRTS 首页元素状态判断物资、芯片副本是否开放，支持活动期间全开放。
- **首页亮点同步**：显示凭证兑换、新增时装和新增模组，并复用 PRTS 首页图片。
- **动态寻访时间轴**：显示精确时间与六星 UP；可选追加两列卡池详情卡片，完整展示卡面。
- **活动与卡池订阅提醒**：订阅当前活动或卡池，在结束前一天的指定时间提醒；群聊中会附带 @ 提醒订阅者。
- **最终图片缓存**：快照数据和展示配置未变化时，直接发送已生成日历，避免重复 T2I 渲染。
- **定时方舟日报**：按指定星期和时间将行动日历发送至配置的 SID 会话。
- **自动生日祝贺**：可单独设置每日发送时间与目标 SID；当天有干员生日时合并发送祝福，无生日时保持静默。
- **异常降级与通知**：数据源或图片接口暂时不可用时优先使用缓存；可向管理员 SID 发送异常、恢复和定时日报状态。
- **轻度猫娘提示语**：默认使用罗德岛终端助手文案，可切换极简正式或自定义模板。

## ⚙️ 配置说明

配置已按用途分组：

- **基础显示与交互**：时间轴、长期活动、页脚等内容展示。
- **自动方舟日报**：指定星期、时间和目标 SID；可选择发送前强制刷新数据源。
- **自动生日祝贺**：独立设置每日发送时间与目标 SID；当天无生日干员时不会发送。
- **缓存与图片渲染**：数据快照与最终图片缓存、图片格式、渲染清晰度、T2I 渲染超时、慢渲染日志阈值与渲染前提示；最终图片保留数量只控制磁盘清理，不构成多级回退链。
- **消息文案与风格**：默认“罗德岛轻度猫娘”；内置风格可预览全部文案，选择自定义后才显示模板编辑器。
- **管理员通知与状态**：管理员 SID、异常告警、恢复通知与冷却时间。
- **数据源与网络**：数据源地址、请求超时和 HTTP 代理；其中三个数据源地址非必要不要修改。

#### 缓存与图片渲染默认值

| 配置项 | 默认值 | 说明 |
|---|---:|---|
| 数据快照缓存时间 | 120 分钟 | 跨北京时间零点自动失效。 |
| 最终图片最长复用时间 | 30 分钟 | 实际不会超过数据快照缓存时间。 |
| 图片格式 | PNG | 可选 PNG（无损）或 JPEG（文件更小）。 |
| 渲染清晰度 | high | 可选 `normal`、`high`、`ultra`；档位越高文字和卡面越清晰。 |
| 慢渲染日志阈值 | 60 秒 | 超过该耗时会记录警告日志。 |
| T2I 渲染超时 | 300 秒 | 主日历与历史日程图片共用；允许范围为 5–300 秒。 |
| 渲染失败回退图片最长陈旧时间 | 12 小时 | 超过后不再发送旧图片。 |

### 自动日报

自动日报按 `Asia/Shanghai` 时区执行。它不会补发插件启动前错过的任务。

需要配置：

- 启用自动方舟日报；
- 选择星期和时间；
- 填写目标 SID 列表；
- 可选是否在发送前强制刷新数据源。

目标 SID 和管理员 SID 必须完整粘贴对应会话 `/sid` 返回的值；不要填写 QQ 号、用户 ID 或截断后的 SID。

### 自动生日祝贺

自动生日祝贺同样按 `Asia/Shanghai` 时区执行，但与自动日报完全独立：

- 启用自动生日祝贺；
- 设置每日发送时间；
- 填写独立的生日祝贺目标 SID 列表；
- 当天没有干员生日时不会发送消息；多名干员同日生日时会合并为一条祝福；
- 每个目标 SID 每天最多成功发送一次，插件重启后也不会重复祝贺。

### 常驻定时任务

除上面两个需要手动开启的任务外，插件启动时还会注册两个常驻任务：

| 任务 | 时间 | 行为 |
|---|---|---|
| 订阅提醒检查 | 每小时整点 | 清理已过期订阅，并向到达提醒时间的订阅者发送提醒；没有待提醒订阅时不产生任何消息。 |
| 每日预缓存 | `cache_and_render.daily_precache_time`，默认每天 04:00 | 强制刷新数据源，并预渲染当天的日历长图和两种帮助长图（共 3 次 T2I 渲染）。 |

两个任务同样按 `Asia/Shanghai` 时区执行，都不会补发插件启动前错过的任务。订阅提醒检查没有开关配置项；每日预缓存可以用 `cache_and_render.daily_precache_enabled` 关闭。

每日预缓存的作用是让白天首次 `/方舟日历` 和 `/方舟日历帮助` 直接命中缓存。代价是每天固定产生一次完整的数据源刷新和 3 次 T2I 渲染。

预缓存时间需要与 `scheduled_report.times` 错开：两个任务用的是各自独立的锁，撞在同一分钟会各自强制刷新数据并并发渲染，既拖慢日报，也会让预缓存的失败排在日报之前发出。检测到撞车时插件会把预缓存每次往后顺延 10 分钟，直到找到不冲突的时间（最多试 6 次），并在日志里记录实际执行时间；顺延后仍然全部冲突才不创建任务。

**错开时请往后调，不要往前调。** 默认的 04:00 对齐的是明日方舟的服务器日切时间：活动和卡池基本都在 04:00 结束，预缓存卡在日切之后才能把它们判为已结束。帮助长图按 `(mode, 日历日期)` 缓存、当天不再重渲染，图里的倒计时和可订阅列表都按快照生成时刻计算，所以把预缓存调到 04:00 之前（例如 03:30），当天的帮助长图和 `/方舟订阅` 列表会一整天留着已经结束的活动。日报设在 04:00 时，把预缓存调到 `04:10` 之类的时间即可。

### 订阅提醒

订阅按 `(活动/卡池, 用户, 会话)` 三元组记录，因此同一个用户在不同会话中的订阅互不影响：

- 订阅目标必须是 `/方舟日历` 当前时间轴上的活动或卡池；
- 提醒时间可选，省略时默认 `12:00`，格式为 24 小时制 `HH:MM`；
- 提醒在结束前一天的指定时间触发，由每小时的检查任务发出，同一条订阅只提醒一次；
- 重新订阅同一目标会更新提醒时间并重置提醒状态；
- 同一个人在同一会话有多条到期订阅时会合并为一条消息，不同订阅者各发一条；
- 活动或卡池结束并从时间轴移除后，对应订阅会被自动清理。

订阅记录写入运行数据目录，插件重启和升级都不会丢失。

#### 群聊提醒的 @ 行为

能否触发平台原生提醒取决于适配器是否实现了 `At` 组件的发送侧转换：

| 平台 | 群聊提醒方式 |
|---|---|
| `aiocqhttp`、`discord`、`kook`、`lark`、`satori` | 平台原生 At，会真正推送提醒 |
| 其他平台 | 纯文本 `@订阅者 ID`，只是文字，不触发提醒 |

私聊提醒不带任何 `@` 前缀。

> 0.4.1 及更早版本的订阅记录保存的是裸会话号而非完整 SID，无法投递提醒。升级到本版本后这些记录会在首次加载时被丢弃并记录一条警告日志，需要重新发送 `/方舟订阅` 建立订阅。

### 消息风格

默认风格为”罗德岛轻度猫娘”，只在普通提示和成功提示中使用少量”喵”。数据源状态、错误和管理员告警保持清晰正式。

可切换为：

- 罗德岛轻度猫娘；
- 极简正式；
- 自定义消息模板。

自定义模板可逐条选择文案来源：

- **留空** 或填入 `@catgirl`：使用”罗德岛轻度猫娘”的这一句；
- 填入 `@plain`：使用”极简正式”的这一句；
- 填入其他任何文字：作为自定义文案。

> 哨兵值不区分大小写，因此 `@CATGIRL`、` @Plain ` 都会识别。完全等于哨兵值时才生效，因此以 `@` 开头的正常文案（例如 `@用户 喵～`）不受影响。

自定义模板支持的变量包括：

```text
{name}
{birthday}
{details}
{candidates}
{names}
{count}
{user}
{time}
{end_time}
{error}
```

其中“今日生日查询祝福”用于 `/方舟生日` 在当天命中生日时追加；“自动生日祝贺文案”用于独立定时任务，分别支持 `{name}` 与 `{names}` / `{count}` 等变量。

## 安装

将插件目录放入 AstrBot 的 `data/plugins/`，在 WebUI 安装依赖后启用插件。

要求：

- AstrBot `>=4.17.0`；
- Python 3.10 或更高版本；
- 网络能够访问配置的数据源和 T2I 渲染服务。

> **为什么插件生图可能较慢？** 本插件使用 AstrBot 系统配置中的 `t2i_strategy` 和 `t2i_endpoint` 进行 HTML 转图片。默认 `t2i_endpoint` 为空时，AstrBot 会调用官方远程 T2I 服务；生成日历时需要将模板、中文字体和图片资源交给远程浏览器截图，因此网络延迟、远程服务排队和长图尺寸都会影响耗时。即使数据资源已经缓存，首次最终图片渲染仍可能较慢；最终图片缓存命中后会直接发送已保存图片。

如果希望减少远程网络延迟，可以在 AstrBot 所在服务器自行部署 [AstrBot T2I Service](https://github.com/AstrBotDevs/astrbot-t2i-service)。



## 缓存

运行数据写入：

```text
data/plugin_data/astrbot_plugin_ark_calendar/
```

其中包含：

- 数据快照缓存；
- 网络图片资源缓存；
- 最终日历图片缓存与帮助长图缓存；
- 管理员告警状态；
- 自动生日祝贺发送状态（按目标 SID 和日期去重）；
- 活动与卡池订阅记录（按活动 ID、用户和会话去重）。

插件升级不会覆盖这些运行时缓存。
