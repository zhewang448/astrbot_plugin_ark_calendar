## v0.3.0

罗德岛行动日历是一款明日方舟信息聚合插件，聚合 PRTS、anything-ics 与 ArknightsGachaData，生成 1440px 宽的活动、寻访与今日作战信息长图，并提供干员生日文字查询、当天生日祝福和独立的自动生日祝贺。

## ✨ 功能特点

- **今日作战信息**：按 PRTS 首页元素状态判断物资、芯片副本是否开放，支持活动期间全开放。
- **首页亮点同步**：显示凭证兑换、新增时装和新增模组，并复用 PRTS 首页图片。
- **动态寻访时间轴**：显示精确时间与六星 UP。
- **最终图片缓存**：快照数据和展示配置未变化时，直接发送已生成日历，避免重复 T2I 渲染。
- **定时方舟日报**：按指定星期和时间将行动日历发送至配置的 SID 会话。
- **自动生日祝贺**：可单独设置每日发送时间与目标 SID；当天有干员生日时合并发送祝福，无生日时保持静默。
- **异常降级与通知**：数据源或图片接口暂时不可用时优先使用缓存；可向管理员 SID 发送异常、恢复和定时日报状态。
- **轻度猫娘提示语**：默认使用罗德岛终端助手文案，可切换极简正式或自定义模板。

## ⚙️ 配置说明

配置已按用途分组：

- **基础显示与交互**：时间轴、长期活动、页脚等内容展示。
- **自动方舟日报**：指定星期、时间和目标 SID；可选择发送前强制刷新数据源。
- **自动生日祝贺**：独立设置每日发送时间与目标 SID；当天无生日干员时不会发送。
- **缓存与图片渲染**：数据快照与最终图片缓存、慢渲染日志阈值、渲染前提示。
- **消息文案与风格**：默认“罗德岛轻度猫娘”；内置风格可预览全部文案，选择自定义后才显示模板编辑器。
- **管理员通知与状态**：管理员 SID、异常告警、恢复通知与冷却时间。
- **数据源与网络**：数据源地址、请求超时和 HTTP 代理；其中三个数据源地址非必要不要修改。

### 自动日报

自动日报按 `Asia/Shanghai` 时区执行。它不会补发插件启动前错过的任务。

需要配置：

- 启用自动方舟日报；
- 选择星期和时间；
- 填写目标 SID 列表；
- 可选是否在发送前强制刷新数据源。

目标 SID 和管理员 SID 可在对应会话使用 `/sid` 获取。

### 自动生日祝贺

自动生日祝贺同样按 `Asia/Shanghai` 时区执行，但与自动日报完全独立：

- 启用自动生日祝贺；
- 设置每日发送时间；
- 填写独立的生日祝贺目标 SID 列表；
- 当天没有干员生日时不会发送消息；多名干员同日生日时会合并为一条祝福；
- 每个目标 SID 每天最多成功发送一次，插件重启后也不会重复祝贺。

### 消息风格

默认风格为“罗德岛轻度猫娘”，只在普通提示和成功提示中使用少量“喵”。数据源状态、错误和管理员告警保持清晰正式。

可切换为：

- 罗德岛轻度猫娘；
- 极简正式；
- 自定义消息模板。

自定义模板支持的变量包括：

```text
{name}
{birthday}
{details}
{candidates}
{names}
{count}
```

其中“今日生日查询祝福”用于 `/方舟生日` 在当天命中生日时追加；“自动生日祝贺文案”用于独立定时任务，分别支持 `{name}` 与 `{names}` / `{count}` 等变量。

## 安装

将插件目录放入 AstrBot 的 `data/plugins/`，在 WebUI 安装依赖后启用插件。

要求：

- AstrBot `>=4.17.0`；
- Python 3.10 或更高版本；
- 网络能够访问配置的数据源和 T2I 渲染服务。

> **为什么插件生图可能较慢？** 本插件使用 AstrBot 系统配置中的 `t2i_strategy` 和 `t2i_endpoint` 进行 HTML 转图片。默认 `t2i_endpoint` 为空时，AstrBot 会调用官方远程 T2I 服务；生成日历时需要将模板、中文字体和图片资源交给远程浏览器截图，因此网络延迟、远程服务排队和长图尺寸都会影响耗时。即使数据资源已经缓存，首次最终图片渲染仍可能较慢；最终图片缓存命中后会直接发送已保存图片。

如果希望减少远程网络延迟，可以在 AstrBot 所在服务器自行部署 [AstrBot T2I Service](https://github.com/AstrBotDevs/astrbot-t2i-service)。



## 缓存

运行数据写入：

```text
data/plugin_data/astrbot_plugin_ark_calendar/
```

其中包含：

- 数据快照缓存；
- 网络图片资源缓存；
- 最终日历图片缓存；
- 管理员告警状态；
- 自动生日祝贺发送状态（按目标 SID 和日期去重）。

插件升级不会覆盖这些运行时缓存。
