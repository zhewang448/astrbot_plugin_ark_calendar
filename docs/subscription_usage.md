# 订阅功能使用说明

## 功能概述

订阅功能允许用户订阅感兴趣的活动或卡池，在它们即将结束前收到提醒。系统会在结束前一天的指定时间自动发送提醒，群聊中会自动@订阅用户。

## 命令说明

### 1. 订阅活动或卡池

```
/方舟订阅 <活动/卡池名称> [提醒时间]
```

**参数说明**：
- `活动/卡池名称`：要订阅的活动或卡池的名称（支持模糊匹配）
- `提醒时间`：可选，格式为 HH:MM，默认为 12:00

**使用示例**：
```
/方舟订阅 感谢庆典
/方舟订阅 感谢庆典 09:30
/方舟订阅 限定寻访 14:00
```

**注意事项**：
- 支持模糊匹配，例如输入"感谢"可以匹配"感谢庆典"
- 如果重复订阅同一活动，会更新提醒时间
- 提醒时间使用 24 小时制

### 2. 取消订阅

```
/方舟取消订阅 <活动/卡池名称>
```

**使用示例**：
```
/方舟取消订阅 感谢庆典
/方舟取消订阅 限定寻访
```

### 3. 查看订阅列表

```
/方舟订阅列表
```

显示当前用户在当前会话的所有订阅，包括：
- 订阅类型（活动/卡池）
- 名称
- 结束时间
- 提醒设置

**命令别名**：
- `/我的方舟订阅`
- `/查看订阅`

## 提醒机制

### 提醒时间

- 系统会在活动/卡池结束前一天的指定时间发送提醒
- 例如：活动于 8月15日 03:59 结束，提醒时间设置为 12:00
  - 则会在 8月14日 12:00 发送提醒

### 提醒内容

提醒消息包含：
- 活动/卡池名称
- 结束时间
- 群聊中会自动@订阅用户

### 提醒频率

- 每个订阅只会提醒一次
- 提醒发送后会自动标记为"已提醒"
- 系统每小时检查一次是否有需要发送的提醒

## 使用场景

### 场景 1：不想错过限定活动

```
用户：/方舟订阅 感谢庆典
系统：好的喵～已为博士订阅「感谢庆典」，将在结束前一天的 12:00 提醒博士喵！
```

活动结束前一天中午，系统会自动提醒：
```
@用户 博士，「感谢庆典」将在明天 03:59 结束，请抓紧时间参与喵～
```

### 场景 2：自定义提醒时间

```
用户：/方舟订阅 限定寻访 20:00
系统：好的喵～已为博士订阅「限定寻访」，将在结束前一天的 20:00 提醒博士喵！
```

### 场景 3：管理多个订阅

```
用户：/方舟订阅列表
系统：博士的订阅列表喵～

1. [活动] 感谢庆典
   结束时间：2026-08-15 03:59
   提醒设置：⏰ 12:00 提醒

2. [卡池] 限定寻访
   结束时间：2026-08-20 03:59
   提醒设置：⏰ 20:00 提醒
```

### 场景 4：取消不需要的订阅

```
用户：/方舟取消订阅 感谢庆典
系统：收到喵～已为博士取消订阅「感谢庆典」。
```

## 数据存储

订阅数据存储在插件数据目录：
```
data/plugin_data/astrbot_plugin_ark_calendar/subscriptions/subscriptions.json
```

数据会持久化保存，插件重启后订阅仍然有效。

## 自动维护

### 过期清理

系统会自动清理以下订阅：
- 活动/卡池已结束
- 活动/卡池不再出现在当前日历中

### 提醒去重

- 每个订阅只会提醒一次
- 提醒发送后会标记为"已提醒"
- 避免重复骚扰用户

## 技术细节

### 时区

所有时间计算基于 `Asia/Shanghai` 时区（UTC+8）

### 检查频率

订阅提醒任务每小时的整点执行一次，检查是否有需要发送的提醒。

### 群聊识别

系统会自动识别群聊会话，在提醒消息中包含@用户功能。

## 常见问题

### Q: 为什么我没有收到提醒？

A: 可能的原因：
1. 还没到提醒时间（结束前一天的指定时间）
2. 提醒已经发送过（检查订阅列表中的状态）
3. 活动/卡池已经结束并被自动清理
4. 插件未运行或定时任务未正常执行

### Q: 可以同时订阅多个活动吗？

A: 可以，没有数量限制。使用 `/方舟订阅列表` 查看所有订阅。

### Q: 订阅是否会在插件重启后丢失？

A: 不会，订阅数据会持久化保存。

### Q: 可以修改已有订阅的提醒时间吗？

A: 可以，再次执行订阅命令并指定新的提醒时间即可。

### Q: 私聊和群聊的订阅是分开的吗？

A: 是的，每个会话（SID）的订阅是独立的。
