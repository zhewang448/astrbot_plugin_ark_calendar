# 配置与定时任务

WebUI 配置按以下顺序展示：基础展示、自动日报、自动生日祝贺、B站动态推送、缓存与图片渲染、消息文案、管理员通知、数据源与网络。

## 图片渲染

| 配置项 | 默认值 | 生效范围 |
|---|---:|---|
| 数据快照缓存时间 | 120 分钟 | 日历数据刷新。 |
| 最终图片最长复用时间 | 30 分钟 | 日报最终图片缓存。 |
| 日报与历史日程图片格式 | PNG | 仅日报与历史日程可切换 PNG/JPEG。 |
| 图片渲染清晰度 | high | 日报、历史日程、帮助图、公招图、B站动态图都会生效。 |
| T2I 渲染超时 | 300 秒 | 所有 HTML 图片模板共用。 |
| 慢渲染日志阈值 | 60 秒 | 所有 HTML 图片模板。 |

帮助图、公招图和 B站动态图固定使用 PNG，以保留文字和细线清晰度；它们仍会使用“图片渲染清晰度”档位。

## 自动日报

按 `Asia/Shanghai` 时区执行，不补发插件启动前错过的任务。依次设置启用开关、目标 SID、星期、时间，以及是否发送前强制刷新数据。

目标 SID 和管理员 SID 都必须填写会话中 `/sid` 返回的完整值，不要填 QQ 号、用户 ID 或截断后的 SID。

## 自动生日祝贺

与自动日报独立运行。设置启用开关、每日时间和目标 SID；当天无生日干员时保持静默，多名干员同日生日时合并为一条消息。每个目标 SID 每天最多成功发送一次。

## B站动态推送

配置顺序为：启用开关、目标 SID、检查间隔、推送类型、渲染阈值、QQ 合并转发、手动列表条数、RSSHub 地址。

“视频”仅是自动推送筛选项：推送内容为图文摘要和原链接，不下载或发送视频文件。图片数超过阈值时，只有 `aiocqhttp` 可额外发送原图合并转发；其他平台发送文字终端图和链接。

新动态判定使用共享状态：同一条动态只要成功投递过一次就会标记为已推送，不会因为目标会话或目标列表变化再次补推旧动态。

首次启用推送时会建立历史基线，不会补推历史动态。

## 每日预缓存与订阅

每日预缓存会在配置时间强制刷新数据，并预渲染日历和两种帮助图。默认 `04:00` 对齐游戏日切；若日报也在该时间运行，预缓存会最多每次顺延 10 分钟，建议直接设置在日报之后，例如 `04:10`。

订阅按“活动或卡池、用户、会话”记录。提醒默认在结束前一天 `12:00` 触发；自定义时间使用 `HH:MM`。活动结束时间会在订阅时固化，插件只在实际提醒时运行一次性任务，不会持续检查活动时间；已结束的订阅会在下次读取或调度时清理。

群聊中的原生 @ 提醒由平台适配器决定；`aiocqhttp`、`discord`、`kook`、`lark`、`satori` 支持原生 At，其他平台使用纯文本 `@订阅者 ID`。
