# 指令与交互

## 普通指令

| 主指令 | 别称 | 说明 |
|---|---|---|
| `/方舟日历` | `/方舟日报`、`/明日方舟日历`、`/舟日历` | 生成活动、寻访和今日作战信息长图。 |
| `/方舟生日 <干员名称>` | `/方舟生日查询`、`/明日方舟生日`、`/舟生日` | 查询干员生日；当天生日会追加祝福。 |
| `/方舟干员 <干员名称>` | `/干员档案`、`/方舟干员档案` | 文字档案：星级职业、生日、公招词条、最近 UP 与黄票商店记录、当前 UP 卡池。 |
| `/方舟日历状态` | `/方舟状态`、`/明日方舟日历状态` | 查看最近快照、数据源和最终图片缓存状态。 |
| `/方舟订阅 <活动/卡池名称> [提醒时间]` | `/订阅方舟活动`、`/订阅卡池` | 在活动或卡池结束前一天提醒；活动商店晚于活动关闭时，会另外在商店关闭前一天提醒。只匹配尚未结束的项目，名称完全一致时优先精确匹配。 |
| `/方舟取消订阅 <活动/卡池名称>` | `/取消订阅方舟`、`/取消订阅卡池` | 取消活动或卡池订阅；取消活动会一并取消其活动商店提醒。 |
| `/方舟订阅列表` | `/我的方舟订阅`、`/查看订阅` | 查看当前会话中的订阅和蹲池干员。 |
| `/方舟蹲池 <干员名称>` | `/蹲池`、`/订阅干员UP` | 卡池 UP 名单出现该干员时提醒，每个卡池只提醒一次；由每日预缓存刷新数据后检查，关闭每日预缓存时不会推送。 |
| `/方舟取消蹲池 <干员名称>` | `/取消蹲池`、`/取消订阅干员UP` | 取消蹲池。 |
| `/方舟动态 [编号]` | `/B站动态`、`/官方动态`、`/方舟B站` | 查看官方 B站动态；带编号时查看详情。 |
| `/方舟公招 <标签1> [标签2] [标签3] …` | `/公招计算`、`/明日方舟公招`、`/舟公招` | 按游戏内 9 小时规则计算公招标签组合与保底星级；默认最多 5 个标签（配置项“公招最多输入标签数”，填 0 不限制），不带参数时显示标签帮助。悄悄告诉你：如果参数是 `all` 或 `*`，会触发阿米娅的小彩蛋。 |
| `/方舟未复刻 [六星/五星/标准/中坚/全部] [数量/all]` | `/未复刻排行`、`/方舟未复刻排行`、`/方舟复刻排行` | 按最近一次出率提升结束时间生成未复刻排行榜；单独填写数量时默认六星，`all` 不区分大小写。 |
| `/方舟日历帮助` | `/方舟日报帮助`、`/明日方舟日报帮助`、`/方舟终端帮助`、`/明日方舟终端帮助` | 显示插件帮助图片。 |

## 管理员指令

| 指令 | 别称 | 说明 |
|---|---|---|
| `/方舟日历刷新` | `/方舟日历更新`、`/方舟日报刷新` | 强制刷新数据源并重新生成日历图片；新图会写入最终图片缓存，之后的 `/方舟日历` 直接复用。 |
| `/方舟历史日程测试 <日期>` | `/方舟回溯测试`、`/方舟日历历史测试` | 以正常日报布局渲染指定日期的历史测试图，不写入日常快照缓存。 |
| `/方舟动态推送测试` | `/测试动态推送` | 忽略已推送状态，将最新 B站动态推送到配置的目标 SID。 |

```text
/方舟未复刻 六星 20

```

## B站动态发送

- 图片数不超过渲染阈值时，文字和全部图片生成一张终端图片，之后附上“查看完整动态”链接。
- 图片数超过阈值时，终端图片只渲染文字，之后附上链接。
- `aiocqhttp` 且启用合并转发时，超阈值动态会额外发送一条原图合并转发消息。
- 其他平台不会发送原图合并转发；超阈值动态只发送文字终端图和链接。
- 视频动态默认只发送图文摘要和原链接。开启“视频动态附带发送视频”后，`/方舟动态 <编号>` 查询和定时推送都会在图文摘要之后通过 [astrbot_plugin_parser](https://github.com/Zhalslar/astrbot_plugin_parser) 下载并发送视频文件；`/方舟动态推送测试` 不追加视频。
