/方舟日历
别名：/方舟日报 / /明日方舟日历 / /舟日历

/方舟生日 <干员名称>
别名：/方舟生日查询 / /明日方舟生日 / /舟生日
以文字查询干员生日；若当天生日则追加祝福
/方舟订阅 <活动/卡池名称> [提醒时间]
别名：/订阅方舟活动 / /订阅卡池
订阅活动或卡池，在结束前一天提醒。
💡 选择下方可订阅项目中的名称
/方舟取消订阅 <活动/卡池名称>
别名：/取消订阅方舟 / /取消订阅卡池
取消订阅活动或卡池。
/方舟订阅列表
别名：/我的方舟订阅 / /查看订阅
查看当前订阅的所有活动和卡池。
/方舟日历状态
别名：/方舟状态 / /明日方舟日历状态
查看最近快照、数据源和最终图片缓存状态
